# PROJECT.md — todo-tui 项目强制约束

> 所有角色启用时必须读取本文件。架构师/工程师在技术决策时逐条对照。
> 以下为全部已定义约束（当前共 4 条）。新增约束需经 proj-lead 审批后在此追加。

---

## 约束清单

| ID    | 约束名     | 规则                                                                          | 违反后果                        |
| ----- | ---------- | ----------------------------------------------------------------------------- | ------------------------------- |
| M-001 | 禁止 unwrap | 非测试代码中一律返回 `Result`，不得使用 `.unwrap()` / `.expect()`（测试豁免） | clippy 报错，`make check` 不通过 |
| M-002 | UI 只读    | `src/ui/` 内所有函数禁止写入 `AppState` 任何字段（只读访问）                  | 破坏单向数据流，架构评审打回     |
| M-003 | 颜色集中   | 颜色常量只在 `src/ui/theme.rs` 定义；其他文件只引用，不得内联颜色值            | 主题不一致，维护成本翻倍         |
| M-031 | 简洁原则   | 100 行能解决的不写 300 行；单次使用的逻辑不抽象为通用组件；没有被要求的灵活性不提前设计 | 过度设计，研发负责人要求重构后再验收 |

---
