## 模块树

> **命名规则**：`{父模块}-{子模块}-…-{角色}-{编号}`，名字本身即上报链。
> 模块内角色（模块架构师、工程师）由研发负责人按规范直接委派（本项目无模块组长层级，研发负责人即工程师直接上级）。

```
研发负责人: dev-lead
├── core        (src/main.rs, src/app.rs, src/config.rs, src/i18n.rs)
│               — 应用入口、状态机、配置、国际化
│
├── models      (src/models/)
│               — 数据结构定义，纯计算，无 I/O
│
├── storage     (src/storage/)
│               — SQLite CRUD、迁移
│
└── ui          (src/ui/)
                — ratatui 渲染层
```

**本项目无模块组长**：规模小（单二进制，4 个顶层模块），研发负责人直接委派模块架构师和工程师。

---

## 递归终止条件

满足以下条件，不设子模块组长：
- 每个顶层模块单人可独立执行
- 模块数量 4 个，未超过 6 个上限
