## 区域说明

### 标题栏（第1行）
- 左侧：应用名 + 版本号
- 右侧：常用快捷键提示（? 帮助，q 退出）
- 背景色：`Color::Blue`，文字：`Color::White` + `Modifier::BOLD`

### 左侧列表面板（占宽 40%）
- 标题：`Todo 列表 (当前序号/总数)`
- 每行格式：`[状态] [优先级] 标题文字    [截止日期]`
- 选中行：`Color::Blue` 背景 + `Color::White` 文字
- 已完成条目：`Color::DarkGray` + `Modifier::CROSSED_OUT`（删除线）
- 截止日期列右对齐，今天到期黄色，过期红色
- 支持滚动（超出屏幕高度时）

### 右侧详情面板（占宽 60%）
- 标题：`详情`
- 字段标签左对齐，值左对齐，标签列宽固定 10 字符
- 优先级显示对应颜色
- 截止日期过期时追加 `⚠ 已过期` 红色提示，今天到期追加 `⚠ 即将到期` 黄色提示
- 无选中条目时显示提示文字 `↑↓ 选择条目`

### 底部状态栏（最后1行）
- 显示当前模式下可用的快捷键
- 背景色：`Color::DarkGray`，文字：`Color::White`
- 不同模式显示不同快捷键（见 docs/ux/keyboard.md）

## 添加/编辑弹窗布局

```
          ┌─────────────────────────────────────────┐
          │  添加 Todo                               │
          │                                         │
          │  标题:    [________________________]     │
          │  分类:    [工作         ▼]               │
          │  优先级:  [中           ▼]               │
          │  截止日期: [YYYY-MM-DD  ]                │
          │                                         │
          │            [Enter] 确认  [Esc] 取消      │
          └─────────────────────────────────────────┘
```

- 弹窗宽度：终端宽度的 60%，最小 50 列
- 弹窗高度：自适应内容
- 当前聚焦字段边框色：`Color::Cyan`
- Tab/Shift+Tab 在字段间切换焦点
