# todo-tui UI 设计规范

**设计师**: UI设计师角色
**日期**: 2026-04-23
**关联需求**: REQ-006, REQ-007

---

## 整体风格

### 设计原则
- **键盘优先**：所有操作可通过键盘完成，鼠标为辅助
- **信息密度**：在有限终端空间内展示最多有用信息
- **即时反馈**：操作结果立即反映在界面上
- **最小干扰**：弹窗/对话框仅在必要时出现

### 颜色方案（ratatui Color）

| 用途 | 颜色 | ratatui 常量 |
|------|------|-------------|
| 选中条目背景 | 深蓝 | `Color::Blue` |
| 高优先级 | 红色 | `Color::Red` |
| 中优先级 | 黄色 | `Color::Yellow` |
| 低优先级 | 绿色 | `Color::Green` |
| 已完成 todo | 灰色 | `Color::DarkGray` |
| 过期截止日期 | 红色粗体 | `Color::Red` + `Modifier::BOLD` |
| 今天截止 | 黄色 | `Color::Yellow` |
| 边框（激活） | 青色 | `Color::Cyan` |
| 边框（非激活） | 灰色 | `Color::Gray` |
| 标题栏 | 白色粗体 | `Color::White` + `Modifier::BOLD` |
| 帮助文字 | 暗灰 | `Color::DarkGray` |

### 图标约定

| 状态 | 图标 | 说明 |
|------|------|------|
| 未完成 | `○` | Unicode U+25CB |
| 已完成 | `●` | Unicode U+25CF |
| 高优先级 | `!` | 红色感叹号前缀 |
| 过期 | `⚠` | 黄色警告图标 |

## 组件规范

### 边框样式
- 所有面板使用 `Borders::ALL` + `BorderType::Rounded`
- 激活面板边框色：`Color::Cyan`
- 非激活面板边框色：`Color::Gray`

### 列表条目格式
```
[状态图标] [优先级色块] 标题文字          [截止日期]
```
示例：
```
○ ! 写季度报告                          04-25
● 买菜                                  ——
```

### 弹窗样式
- 居中显示，宽度 60%，高度自适应
- 背景色：`Color::Black`（覆盖底层）
- 标题加粗，内容正常字重
- 底部显示确认/取消快捷键

---

## 响应式规范

| 终端宽度 | 布局调整 |
|---------|---------|
| ≥ 100 列 | 左栏 40% / 右栏 60% |
| 80-99 列 | 左栏 45% / 右栏 55% |
| < 80 列 | 单栏模式（列表/详情切换） |
| < 24 行 | 隐藏底部状态栏 |
