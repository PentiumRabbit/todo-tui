## 应用状态机

```
                    ┌─────────────────┐
                    │   Normal Mode   │  ← 默认模式，列表浏览
                    └────────┬────────┘
                             │
          ┌──────────────────┼──────────────────┐
          │ [a]              │ [e]              │ [d]
          ▼                  ▼                  ▼
   ┌─────────────┐   ┌─────────────┐   ┌─────────────┐
   │  Add Mode   │   │  Edit Mode  │   │Delete Confirm│
   └──────┬──────┘   └──────┬──────┘   └──────┬──────┘
          │                 │                  │
     [Enter]确认        [Enter]确认        [y/Enter]确认
     [Esc]取消          [Esc]取消          [n/Esc]取消
          │                 │                  │
          └──────────────────┴──────────────────┘
                             │
                             ▼
                    ┌─────────────────┐
                    │   Normal Mode   │
                    └─────────────────┘

        [?] → Help Mode（叠加弹窗，Esc/? 关闭）
        [/] → Search Mode（底部输入框，Esc 退出）
```

## 面板焦点状态机（REQ-008）

```
┌──────────────────┐   [← / Tab]   ┌──────────────────┐
│  Todo 列表面板    │ ────────────→ │   标签面板        │
│  focus=false     │               │   focus=true      │
│                  │ ←──────────── │                   │
└──────────────────┘   [→ / Tab]   └──────────────────┘
```

- 焦点切换仅在 Normal Mode 下响应
- Search / Detail / Add / Edit / DeleteConfirm 模式下方向键不触发面板切换
- 两个切换键（`←/→` 与 `Tab`）效果完全一致，互为冗余
- **标签面板获焦后，`j/k` 移动光标时 Todo 列表实时跟随过滤（无需 Enter 确认）**
- `Enter` 仅负责切换焦点回 Todo 面板，过滤条件以当前光标标签为准

## 完整快捷键映射

### Normal Mode（列表浏览）

| 按键 | 动作 | 说明 |
|------|------|------|
| `j` / `↓` | 下移选中 | 到底部后停止 |
| `k` / `↑` | 上移选中 | 到顶部后停止 |
| `g` / `Home` | 跳到顶部 | |
| `G` / `End` | 跳到底部 | |
| `←` / `Tab` | 焦点切换到标签面板 | 见面板焦点状态机 |
| `a` | 进入 Add Mode | 打开添加弹窗 |
| `e` | 进入 Edit Mode | 打开编辑弹窗（需有选中条目） |
| `d` | 进入 Delete Confirm | 打开删除确认弹窗（需有选中条目） |
| `Space` | 切换完成状态 | 立即持久化 |
| `/` | 进入 Search Mode | 底部出现搜索输入框 |
| `?` | 打开帮助弹窗 | |
| `q` | 退出应用 | 有未保存内容时提示 |

### 标签面板（focus_tag_panel = true）

| 按键 | 动作 | 说明 |
|------|------|------|
| `j` / `↓` | 下移选中标签 | |
| `k` / `↑` | 上移选中标签 | |
| `→` / `Tab` | 焦点切换回 Todo 面板 | 过滤条件以当前光标标签为准 |
| `Enter` / `Space` | 焦点切换回 Todo 面板 | 同 `→/Tab`，过滤已实时生效 |
| `q` | 退出应用 | |

### Add / Edit Mode（表单编辑）

| 按键 | 动作 | 说明 |
|------|------|------|
| `Tab` | 下一个字段 | 循环切换 |
| `Shift+Tab` | 上一个字段 | 循环切换 |
| `Enter` | 确认提交 | 在最后一个字段或任意时 |
| `Esc` | 取消关闭 | 不保存任何修改 |
| 文字输入 | 编辑当前字段 | |
| `Backspace` | 删除前一字符 | |
| `↑` / `↓` | 下拉选项切换 | 在分类/优先级字段 |

### Delete Confirm Mode

| 按键 | 动作 |
|------|------|
| `y` / `Enter` | 确认删除 |
| `n` / `Esc` | 取消 |

### Search Mode

| 按键 | 动作 |
|------|------|
| 文字输入 | 实时过滤列表 |
| `Enter` | 确认搜索结果，回到 Normal Mode |
| `Esc` | 清空搜索，回到 Normal Mode |
| `↑` / `↓` | 在搜索结果中移动 |

### Help Mode（弹窗叠加）

| 按键 | 动作 |
|------|------|
| `?` / `Esc` | 关闭帮助弹窗 |

## 边界情况处理

| 情况 | 处理方式 |
|------|---------|
| 列表为空时按 `e` / `d` | 无响应（不打开弹窗） |
| 列表为空时按 `Space` | 无响应 |
| Add Mode 标题为空按 Enter | 显示字段错误提示，不提交 |
| 截止日期格式错误 | 字段变红，显示格式提示 |
| 终端窗口过小（< 80×24） | 显示最小尺寸警告覆盖层 |
