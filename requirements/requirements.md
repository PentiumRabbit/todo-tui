# todo-tui 需求文档

**项目**: todo-tui
**技术栈**: Rust + ratatui + crossterm + rusqlite
**提出日期**: 2026-04-23
**PM**: PM角色

---

## 项目背景

终端 TUI 待办事项管理应用，使用 Rust 开发，基于 ratatui 框架构建交互式终端界面，数据持久化到本地 SQLite。

## 目标用户

习惯在终端工作的开发者，需要轻量、快速、键盘驱动的任务管理工具。

## 功能需求

#### REQ-001: todo 基础 CRUD

**类型**: 功能
**优先级**: P0
**分配给**: 研发负责人
**提出日期**: 2026-04-23
**状态**: 待实现

**用户故事**: 作为用户，我希望能添加、删除、编辑、标记完成 todo 条目，以便管理我的任务列表。

**需求描述**:
- 添加：输入标题创建新 todo（必填），支持同时填写分类/优先级/截止日期（可选）
- 删除：选中条目后按 `d` 删除，需弹出确认对话框
- 编辑：按 `e` 进入编辑模式，可修改标题、分类、优先级、截止日期
- 标记完成：按 `Space` 切换完成/未完成状态

**验收标准**:
- [ ] 添加 todo 后立即显示在列表中
- [ ] 删除前有确认提示，取消不删除
- [ ] 编辑保存后列表实时更新
- [ ] 完成状态切换后图标立即变化（● → ○）

#### REQ-008: 左右键在标签面板与 Todo 面板间切换

**类型**: 交互
**优先级**: P1
**分配给**: 交互设计师 / 研发负责人
**提出日期**: 2026-04-29
**状态**: 已关闭

**用户故事**: 作为用户，我希望在首页用左右方向键在标签面板和 Todo 列表面板间来回切换焦点，以便保持键盘操作连贯性，不需要记忆额外的 Tab 键。

**需求描述**:
- 当焦点在 Todo 列表面板（Normal 模式）时，按 `←` 将焦点切换到标签面板
- 当焦点在标签面板时，按 `→` 将焦点切换回 Todo 列表面板
- 原有 `Tab` 键行为保持不变（双向互补，不替代）
- 切换后焦点高亮边框应立即更新反映当前焦点所在面板
- 左右键仅在 Normal 模式下生效；Search / Detail / Form 等模式不响应此切换

**场景矩阵**:

| 维度 | 场景 | 预期行为 |
|------|------|---------|
| 输入有效性 | Normal 模式，焦点在 Todo 面板，按 `←` | 焦点切换到标签面板，边框高亮变化 |
| 输入有效性 | 标签面板获焦，按 `→` | 焦点切换回 Todo 面板，边框高亮变化 |
| 输入有效性 | Normal 模式，焦点在 Todo 面板，按 `→` | 无响应（已在右侧，无右侧面板） |
| 输入有效性 | 标签面板获焦，按 `←` | 无响应（已在左侧，无更左侧面板） |
| 前置条件/状态 | Search 模式下按 `←` | 不切换面板，字符 `←` 不写入搜索框（方向键不是字符） |
| 前置条件/状态 | Detail / Form / DeleteConfirm 模式下按 `←` / `→` | 不触发面板切换，各模式原有行为不变 |
| 幂等性 | 已在标签面板，连续按多次 `→` | 每次都保持焦点在 Todo 面板，不产生副作用 |
| 来源/优先级 | `←` 与 `Tab` 同时作为切换键 | 两者效果完全一致，互为冗余快捷键 |

**不适用维度说明**: 数量规模边界不适用（切换操作无数量概念）

**验收标准**:
- [x] Normal 模式下 `←` 从 Todo 面板切换到标签面板
- [x] 标签面板下 `→` 切换回 Todo 面板
- [x] `Tab` 原有行为不受影响
- [x] Search / Detail / Form 模式下方向键不触发面板切换
- [x] 状态栏提示更新为 `[←/Tab]` / `[→/Tab]`

**备注**: 实现已在 commit `32db112` 完成；本条目为补录流程文档。
