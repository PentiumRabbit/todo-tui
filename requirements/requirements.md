# todo-tui 需求文档

**项目**: todo-tui
**技术栈**: Rust + ratatui + crossterm + rusqlite
**提出日期**: 2026-04-23
**PM**: PM角色

---

## 项目背景

终端 TUI 待办事项管理应用，使用 Rust 开发，基于 ratatui 框架构建交互式终端界面，数据持久化到本地 SQLite。

## 目标用户

习惯在终端工作的开发者，需要轻量、快速、键盘驱动的任务管理工具。

---

## 功能需求

#### REQ-001: todo 基础 CRUD

**类型**: 功能
**优先级**: P0
**分配给**: 研发负责人
**提出日期**: 2026-04-23
**状态**: 待实现

**用户故事**: 作为用户，我希望能添加、删除、编辑、标记完成 todo 条目，以便管理我的任务列表。

**需求描述**:
- 添加：输入标题创建新 todo（必填），支持同时填写分类/优先级/截止日期（可选）
- 删除：选中条目后按 `d` 删除，需弹出确认对话框
- 编辑：按 `e` 进入编辑模式，可修改标题、分类、优先级、截止日期
- 标记完成：按 `Space` 切换完成/未完成状态

**验收标准**:
- [ ] 添加 todo 后立即显示在列表中
- [ ] 删除前有确认提示，取消不删除
- [ ] 编辑保存后列表实时更新
- [ ] 完成状态切换后图标立即变化（● → ○）

#### REQ-002: 分类/标签系统

**类型**: 功能
**优先级**: P1
**分配给**: 研发负责人
**提出日期**: 2026-04-23
**状态**: 待实现

**用户故事**: 作为用户，我希望为 todo 添加分类，以便按类型过滤查看任务。

**需求描述**:
- 每个 todo 可属于一个分类（默认"无分类"）
- 分类可自由创建和删除
- 列表支持按分类过滤（左侧面板或顶部 Tab）
- 内置分类：工作、生活、学习（可删除）

**验收标准**:
- [ ] 创建 todo 时可选择或新建分类
- [ ] 过滤后列表只显示对应分类的 todo
- [ ] 分类名显示在 todo 详情中
- [ ] 删除分类时，该分类下的 todo 归入"无分类"

#### REQ-003: 优先级系统

**类型**: 功能
**优先级**: P1
**分配给**: 研发负责人
**提出日期**: 2026-04-23
**状态**: 待实现

**用户故事**: 作为用户，我希望为 todo 设置优先级（高/中/低），以便按重要性排序任务。

**需求描述**:
- 三级优先级：高（P1）、中（P2）、低（P3），默认中
- 列表中显示优先级标识（颜色区分）
- 支持按优先级排序
- 高优先级 todo 使用红色/醒目颜色标注

**验收标准**:
- [ ] 创建/编辑时可选择优先级
- [ ] 高优先级显示红色标识，中优先级黄色，低优先级绿色
- [ ] 按优先级排序时高优先级在前

#### REQ-004: 截止日期

**类型**: 功能
**优先级**: P1
**分配给**: 研发负责人
**提出日期**: 2026-04-23
**状态**: 待实现

**用户故事**: 作为用户，我希望为 todo 设置截止日期，以便追踪任务时限。

**需求描述**:

**验收标准**:
- [ ] 可设置和清空截止日期
- [ ] 过期 todo 在列表中有红色视觉提示
- [ ] 今天到期有黄色视觉提示
- [ ] 详情面板正确显示截止日期

#### REQ-005: SQLite 数据持久化

**类型**: 功能 / 架构
**优先级**: P0
**分配给**: 研发负责人
**提出日期**: 2026-04-23
**状态**: 待实现

**用户故事**: 作为用户，我希望 todo 数据在程序重启后仍然保留，以便长期使用。

**需求描述**:
- 数据库文件存储于 `~/.todo-tui/todos.db`
- 首次启动自动创建数据库和表结构
- 所有 CRUD 操作实时同步到数据库
- 支持数据库迁移（schema 版本管理）

**验收标准**:
- [ ] 程序重启后数据完整保留
- [ ] 首次启动自动初始化数据库
- [ ] CRUD 操作后立即持久化（无需手动保存）

## 非功能需求

| 类型 | 要求 |
|------|------|
| 性能 | 启动时间 < 100ms，列表滚动无卡顿（支持 1000+ 条目） |
| 兼容性 | macOS / Linux 终端，最低 80×24 终端尺寸 |
| 可靠性 | 数据库写入失败时显示错误提示，不丢失数据 |
