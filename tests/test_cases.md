#### TC-CRUD-001: 添加基础 Todo

| 字段 | 内容 |
|------|------|
| **用例ID** | TC-CRUD-001 |
| **用例名称** | 添加一个有标题的 Todo |
| **关联需求** | REQ-001 |
| **前置条件** | 程序已启动，处于 Normal 模式 |
| **测试步骤** | 1. 按 `a` 打开添加弹窗 2. 输入标题 "测试任务" 3. 按 Enter 确认 |
| **预期结果** | 弹窗关闭，列表顶部出现 "测试任务"，状态为未完成 |
| **自动化** | `cargo test test_insert_todo` |
